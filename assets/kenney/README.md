# Assets Kenney 3D

Dépose ici les trois archives **sans les renommer** :

- `kenney_car-kit.zip`
- `kenney_city-kit-suburban_20.zip`
- `kenney_city-kit-roads.zip`

Le workflow Android extrait automatiquement les modèles GLB nécessaires.

La ville utilise ensuite :
- de vraies voitures Kenney 3D en circulation et en stationnement ;
- un quartier résidentiel Kenney ;
- des lampadaires, feux et panneaux Kenney.

Si une archive manque, le jeu conserve automatiquement son décor de secours au lieu de devenir vide.
